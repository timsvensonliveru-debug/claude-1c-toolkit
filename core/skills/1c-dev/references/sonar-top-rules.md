# Замечания SonarQube (BSL), которые встречаются чаще всего

Корпоративные CI на основе SonarQube с плагином BSL присылают замечания по ключам диагностик BSL Language Server.
Ключи те же, что в `bsl-ls`, поэтому их видно ещё до коммита. Ниже девять ключей, на которые приходится почти вся
масса замечаний, и как писать код, чтобы они не появлялись. Правь код при написании, а не после письма из CI.

| Ключ | Что значит | Как писать |
|---|---|---|
| `QueryNestedFieldsByDot` | в тексте запроса поле читается через точку по ссылке (`Док.Контрагент.ИНН`) | явное `ЛЕВОЕ СОЕДИНЕНИЕ Справочник.Контрагенты КАК Контрагенты ПО Док.Контрагент = Контрагенты.Ссылка` и поле `Контрагенты.ИНН`. Точка по ссылке прячет неявные соединения, план запроса становится непредсказуемым |
| `MissingParameterDescription` | у документированного метода не описан параметр | в комментарии раздел `Параметры:` и строка `Имя - Тип - пояснение` на каждый параметр |
| `MissingReturnedValueDescription` | у функции нет раздела о возвращаемом значении | раздел `Возвращаемое значение:` и строка `Тип - пояснение` |
| `CognitiveComplexity` (порог 15) | слишком много вложенных ветвлений и циклов | ранний выход (`Возврат`, `Продолжить`), вынос тела цикла и веток в отдельные методы, плоские условия |
| `CyclomaticComplexity` (порог 20) | слишком много ветвей | таблица соответствий или разбиение по ветке на метод |
| `UnusedLocalMethod` | неэкспортный метод нигде не вызывается | удалить; если нужен снаружи, сделать экспортным в нужной области |
| `JoinWithVirtualTable` | соединение с виртуальной таблицей регистра | сначала `ПОМЕСТИТЬ` виртуальную таблицу (с параметрами и отбором) во временную таблицу, потом соединять её |
| `EmptyCodeBlock` | пустая ветка или обработчик | убрать или оставить комментарий, почему пусто |
| `IfElseIfEndsWithElse` | цепочка `ИначеЕсли` без `Иначе` | добавить `Иначе` с явным действием: исключение или комментарий, почему остальные случаи невозможны |

Формат комментария к методу:

```bsl
// Возвращает признак того, что заказ можно закрыть.
//
// Параметры:
//  Заказ - ДокументСсылка.ЗаказКлиента - проверяемый заказ
//  УчитыватьОплату - Булево - проверять ли полную оплату
//
// Возвращаемое значение:
//  Булево - Истина, если закрытие допустимо
Функция ЗаказМожноЗакрыть(Заказ, УчитыватьОплату = Истина) Экспорт
```

Перед выдачей кода: прогнать `bsl-ls` по изменённым файлам и закрыть эти ключи, даже если они Warning, а не Error.
Пока гейт SonarQube информационный, замечания всё равно приходят автору в письме, поэтому закрывать надо сразу.

Необязательная автопроверка: после правки `.bsl` хук сам прогоняет BSL LS и показывает только эти девять ключей. Нужны `BSL_JAR` и java (подойдёт JDK из 1C:EDT). Нет чего-то из этого или стоит `AI_TOOLKIT_BSLLS_GATE=off`: хук молчит, работа не ломается.
