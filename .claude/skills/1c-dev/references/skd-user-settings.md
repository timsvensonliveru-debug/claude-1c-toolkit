# Пользовательские настройки СКД: порядок наложения и где что менять

Читай, когда нужно задать значение параметра или отбора в отчёте так, чтобы оно и сработало, и не затёрло выбор пользователя, или когда настройки "не применяются". Метки: **[надёжно]**, **[проверить]** (сверь по справке и по коду БСП своей базы).

## Ловушки (сначала)
1. Значение, заданное в варианте, не перекроет значение, которое пользователь уже менял в пользовательских настройках. Хочешь повлиять на то, что видит пользователь, ставь значение в обработчике пользовательских настроек и включай `Использование`. **[надёжно]**
2. Параметр с `Использование = Ложь` в запрос не попадает, как бы ни было заполнено значение.
3. Элемент настройки ищи по идентификатору (`ИдентификаторПользовательскойНастройки`), не по индексу: порядок элементов может отличаться между вариантами. Индекс допустим только для настроек, которые ты сам только что создал.
4. Параметры вывода называются по-программному (`ВыводитьОтбор`, `Заголовок`, `МакетОформления`), не как в окне. Не угадывай, смотри список `Настройки.ПараметрыВывода`.
5. Обработчик вызывается много раз (открытие, выбор варианта, загрузка настроек). Он должен быть идемпотентным: без накопления элементов при повторном вызове.
6. Фиксированные настройки пользователь не меняет и не видит; не клади туда то, что должно выбираться.

## Порядок наложения
Настройки схемы по умолчанию → настройки варианта → пользовательские настройки. Позднее перекрывает раннее для того, что пользователь реально задавал. **[надёжно]**

В форме отчёта на управляемых формах доступны обработчики. Имена проверены по справке платформы 8.3.27; точные параметры и обёртки подсистемы вариантов отчётов сверь по своей версии БСП:
- `ПередЗагрузкойВариантаНаСервере(Настройки)` — менять сам вариант до загрузки в компоновщик;
- `ПриЗагрузкеВариантаНаСервере(Настройки)` — после загрузки варианта;
- `ПередЗагрузкойПользовательскихНастроекНаСервере(Настройки, ИспользуютсяСтандартныеНастройки)` — менять пользовательские настройки до применения;
- `ПриЗагрузкеПользовательскихНастроекНаСервере(Настройки, ИспользуютсяСтандартныеНастройки)` — после загрузки пользовательских настроек. Обработчика с именем «После…» в платформе нет.

## Что такое пользовательская настройка
Любой элемент настроек (отбор, параметр, порядок, условное оформление, группировка), у которого включено "Включать в пользовательские настройки". Режим показа: быстрый доступ (на форме) или обычный (в окне настроек). У элемента есть `ИдентификаторПользовательскойНастройки`, по нему связываются настройка варианта и пользовательская.

## Шаблоны

Задать значение параметра с учётом выбора пользователя:

```bsl
&НаСервере
Процедура ПередЗагрузкойПользовательскихНастроекНаСервере(Настройки, ИспользуютсяСтандартныеНастройки)
    Для Каждого Элемент Из Настройки.ПользовательскиеНастройки.Элементы Цикл
        Если ТипЗнч(Элемент) = Тип("ЗначениеПараметраНастроекКомпоновкиДанных")
            И Элемент.Параметр = Новый ПараметрКомпоновкиДанных("НачалоПериода")
            И Не Элемент.Использование Тогда
            Элемент.Значение = НачалоМесяца(ТекущаяДатаСеанса());
            Элемент.Использование = Истина;
        КонецЕсли;
    КонецЦикла;
КонецПроцедуры
```
Здесь значение ставится, только если пользователь параметр не включал (иначе его выбор бы затёрли).

Найти элемент пользовательской настройки по идентификатору: перебери `Настройки.ПользовательскиеНастройки.Элементы` и сравни `ИдентификаторПользовательскойНастройки`. Метод `ПолучитьОбъектПоИдентификатору` принимает `ИдентификаторКомпоновкиДанных`, а не строку идентификатора пользовательской настройки, поэтому для строки он не подходит. Альтернатива: `ПользовательскиеНастройки.ПолучитьОсновныеНастройкиПоИдентификаторуПользовательскойНастройки(Идентификатор)` (с 8.3.13).

## Правила
- Умолчание для всех вариантов ставь в настройках схемы; для одного варианта в самом варианте; "за пользователя" в пользовательских.
- Нужно выставить значение независимо от выбора пользователя (например, жёстко ограничить период по правам): делай это после загрузки пользовательских настроек, в обработчике компоновки результата, а не в варианте.
- Ограничение значения по правам доступа — это не фильтр отчёта, а ограничение доступа (RLS) на данные; не подменяй одно другим.
- Зависимые параметры (договор по контрагенту) оформляй связью параметров выбора в настройке поля, а не ручной очисткой в обработчике.

## Как проверить
Сценарий в тест-базе: скомпонуй отчёт с вариантом "как есть", затем с пользовательской настройкой, меняющей значение, и сравни. Значение параметра и отбор должны влиять на число строк. Без прогона считать поведение непроверенным.

## Не проверено
Порядок вызова обработчиков в твоей версии БСП, особенности подсистемы вариантов отчётов, хранилища вариантов и настроек (общие и пользовательские).
